### 🧠 Featured AI Systems & Architectures

#### 1. ⚡ **Spec-Driven E2E Coder & Tester Agent Framework**
- **Methodology:** Follows strict Spec-Driven Development principles to guarantee direct traceability from specification requirements to autonomous code generation and test verification.
- **Vector Knowledge Base (KB):** Engineered a custom KB powered by **PGVector** (PostgreSQL) hosted on a dedicated Linux VM exposing REST endpoints.
- **Syntax Chunking & Vector Search:** Developed an **AST Chunker** (Section & Block boundaries) paired with **HNSW (Hierarchical Navigable Small World)** vector indexing and `text-embedding-3-large` embeddings.
- **Orchestration Graph:** Built a reasoning graph using **LangGraph** paired with **GPT-4o-mini**, driving autonomous feature edits, automated test verification, report generation, and GitLab CI/CD pipeline triggers.

#### 2. 🚀 **Multi-Agent RAG Compliance & V&V Automation**
- **Multi-Agent Architecture:** Engineered multi-agent RAG pipelines using **CrewAI**, KW Filters, and **LLM-as-a-Judge** evaluation frameworks.
- **Document Intelligence:** Built compliance systems that convert architecture diagrams and design docs into standardized compliance sheets, achieving **95% effort reduction** (4 days → <2 hours).

#### 3. 👁️ **Medical Computer Vision & Deep Neural Networks**
- **PneuNetV1 Pneumothorax Classifier (*IEEE Access 2023*):** Deep Convolutional Neural Network (CNN) for automated pneumothorax detection from Chest X-Ray (CXR) images.
- **Intracranial Brain Tumor Diagnosis (*MDPI 2022*):** Selective CNN data modeling technique for high-precision tumor diagnosis from MRI scans.
- **Retinal Vessel Segmentation (*MIUA Cambridge University*):** Advanced image processing algorithms for automated retinal blood vessel extraction.

#### 4. 📊 **High-Throughput Streaming & Distributed Data ETL**
- **Real-Time Data Pipelines:** Built streaming ETL pipelines using **Apache Spark**, **Scala**, **Kafka**, and **Flink** on Databricks for healthcare data transformation, processing **40,000+ records/day**.
- **Cloud Infrastructure Migration:** Led cloud modernization initiatives from Azure to AWS (EKS, EC2, S3, CloudWatch), cutting infrastructure costs by **15%**.
